# Cutie Pet 🐹

바탕화면 위에 사는 귀여운 펫 캐릭터와 **Claude**로 대화하는 데스크톱 앱이에요.
건국대학교 AI 게이트웨이의 API 키로 동작하고, 캐릭터(햄스터 4종)와 이름을 바꾸고, 쓸 AI 모델도 골라서 쓸 수 있어요. 말투는 항상 공손한 존댓말이에요.

[**⬇️ 최신 버전 다운로드**](https://github.com/scarypants/cutie-pet-releases/releases/latest)

> **건국대 학생이라면**: 아래 [1. 설치](#1-설치) → [2. API 키 발급](#2-api-키-발급) → [3. 처음 실행](#3-처음-실행하기) 순서로 따라 하면 5분이면 끝나요.

---

## 1. 설치

1. [**Releases 페이지**](https://github.com/scarypants/cutie-pet-releases/releases/latest)에서 가장 최신 버전의 `CutiePet Setup x.x.x.exe`를 내려받으세요.
2. 파일을 실행하면 자동으로 설치되고 바로 앱이 켜져요. (관리자 권한, Node.js 설치 모두 필요 없어요.)
3. **"Windows의 PC 보호" 화면이 뜨면** 앱이 정식 서명 인증서 없이 배포돼서 나오는 경고예요.
   `추가 정보` → `실행`을 누르면 돼요.

- 지원: Windows 10 / 11 (64비트)
- 설치 위치: `%LOCALAPPDATA%\Programs\CutiePet`
- 삭제: Windows 설정 → 앱 → 설치된 앱 → **CutiePet** 삭제


---

## 2. API 키 발급

이 앱은 **건국대 AI 게이트웨이에서 발급한 API 키로만** 동작해요. (다른 서비스의 키는 사용할 수 없어요.)

1. <https://aichat.kku.ac.kr/dashboard/developers> 에 접속해서 학교 계정으로 로그인하세요.
2. 개발자(Developers) 페이지에서 **API 키를 발급**하고 복사해 두세요.
   (화면 구성은 학교 서비스 사정에 따라 달라질 수 있어요.)

> ⚠️ **API 키는 비밀번호와 같아요.**
> 카톡·깃허브·스크린샷 등 다른 사람이 볼 수 있는 곳에 절대 올리지 마세요.
> 실수로 노출했다면 발급 페이지에서 키를 폐기하고 새로 발급하세요.

---

## 3. 처음 실행하기

앱을 처음 켜면 **설정 창**이 자동으로 열려요.

1. **API 키** 칸에 발급받은 키를 붙여 넣어요.
2. (선택) **햄스터**와 **이름**을 골라요.
3. (선택) **AI 모델**에서 쓸 AI를 골라요. **Claude · GPT · Gemini · Grok · Perplexity** 탭에서 모델을 고르면 돼요. 키를 입력하면 쓸 수 있는 모델 목록이 자동으로 나오고, 고르지 않으면 기본 모델(`claude-sonnet-5-5`)을 써요.
4. **저장**을 누르면 끝! 오른쪽 아래에 캐릭터가 나타나요.

## 4. 사용법

| 동작 | 결과 |
|---|---|
| 캐릭터 **클릭** | 말풍선 입력창 열기 / 다시 클릭하면 닫기 |
| **Enter** | 메시지 보내기 (**Shift+Enter**는 줄바꿈) |
| **Esc** | 답변 중지 (답변이 없을 땐 말풍선 닫기) |
| **Ctrl + Alt + H** | 어디서든 펫을 불러서 바로 입력 (창이 숨겨져 있어도 나타나요) |
| 보내기 버튼이 **■**일 때 | 누르면 답변을 중지해요 |
| 캐릭터 **드래그** | 화면 어디로든 옮기기 (위치는 저장돼요) |
| **📷 화면 첨부** 버튼 | 켜면 질문마다 화면도 함께 보내요 (기본은 **꺼짐**, 아래 [화면 보고 질문하기](#화면-보고-질문하기) 참고) |
| **✂ 영역 선택** 버튼 | 화면에서 드래그로 영역을 골라 그 부분만 첨부 |
| 말풍선 위쪽의 **⤢** 버튼 | 큰 대화창 열기 |
| 캐릭터 **우클릭** | 메뉴 열기 (아래 참고) |
| **트레이 아이콘** (작업표시줄 오른쪽) | 펫 보이기/숨기기, 설정, 종료 |

**우클릭 메뉴**

- **햄스터 색상**: 도토리 · 치즈 · 먹구름 · 알밤
- **크기 조절**: 작게 · 보통 · 크게
- **가끔 산책하기**: 켜 두면 가만히 있을 때 가끔 좌우로 걸어 다녀요
- **대화 초기화**: 이전 대화를 모두 지워요
- **설정** / **종료**

**알아두면 좋은 점**

- 대화는 최근 20턴까지 기억해서 맥락이 이어져요.
- 말풍선에는 내가 보낸 말과 답변이 함께 보여요. 30초 뒤에 자동으로 닫히지만(**마우스를 올려 두거나 스크롤하는 동안, 글을 쓰는 중이거나 답을 받는 중에는 닫히지 않아요**) 대화 내용은 남아 있어요.
- 답변을 기다리는 동안(생각 중)은 **작은 햄스터 3마리가 하나씩 나타났다 사라지는** 애니메이션이 나와요. (선택한 햄스터 모습 그대로예요.)
- 답변이 오기 시작하면 **글자가 하나씩 나타나요.** 깜빡이는 커서가 보이는 동안은 보내기 버튼이 **■ 중지**로 바뀌어요. 중지하면 지금까지 쓴 부분은 남아요.
- 마지막 답변 아래의 **↻ 다시 생성**을 누르면 같은 질문에 새 답변을 받아요. (화면을 함께 보냈다면 같은 화면으로 다시 물어봐요.)
- 말풍선 위쪽 모델 이름 옆의 **`2,986 / 3,000 크레딧`**은 **이번 달 남은 크레딧 / 한도**예요. 20% 이하면 주황색, 5% 이하면 빨간색으로 바뀌고, 마우스를 올리면 `남은 양 / 한도 · 초기화 날짜`가 나와요.
- 답변 아래의 **`약 4.2 크레딧 사용`**은 **그 답변에 쓴 크레딧**이에요. (질문 전후 잔액의 차이라서, 같은 시간에 웹에서 쓴 양이 섞이면 조금 다를 수 있어요.) 질문마다 얼마나 드는지 확인하면서 모델을 고르세요.
- 설정의 **글자 크기**(작게 · 보통 · 크게 · 아주 크게)로 말풍선과 큰 대화창의 글자 크기를 바꿀 수 있어요.
- 답변의 **마크다운 서식**(굵게, 기울임, 목록, `코드`, 코드 블록, 제목, 인용, 링크)이 보기 좋게 표시돼요. 링크를 누르면 기본 브라우저로 열려요. (표는 지원하지 않아요.)
- 말풍선은 대화가 길어져도 창 위쪽이 잘리지 않고, 넘치면 안에서 스크롤돼요.
- 새 답변이 오면 **답변의 맨 처음부터** 보여요. 답변이 말풍선보다 길어도 아래부터 보이지 않고, 처음부터 읽으면서 스크롤하면 돼요.
- 말풍선 위쪽의 **⤢** 버튼(또는 말풍선보다 긴 답변 아래에 나타나는 **큰 창에서 보기**)으로 **큰 대화창**을 열 수 있어요. 크기를 마음대로 조절할 수 있고, 지금까지의 대화를 한눈에 읽고 답변을 **복사**할 수 있어요. 대화는 말풍선에서 계속 이어가면 큰 창에도 바로 반영돼요.
- 말풍선의 **위·왼쪽·오른쪽 가장자리**나 **왼쪽 위 모서리**를 끌어서 말풍선 크기를 직접 조절할 수 있어요. 위로 끌면 더 위쪽까지 늘어나요. 크기는 저장되고, 가장자리를 **더블클릭**하면 원래 크기로 돌아와요.
- 말풍선 위쪽의 **⚙** 버튼으로 바로 설정을 열 수 있어요. (우클릭 메뉴와 트레이에서도 열 수 있어요.)
- 말풍선은 화면 가장자리에서도 잘리지 않게 안쪽으로 밀려요.

### 크레딧 (월 3,000)

건국대 KU LLM은 **매달 1인당 3,000 크레딧**이 지급되고 **매월 1일에 초기화**돼요(남은 크레딧은 이월되지 않아요). 이 앱은 게이트웨이의 잔액·사용량 조회 기능을 써서 보여 줘요.

- **설정 → 이번 달 크레딧**: 남은 크레딧 막대, 다음 초기화 날짜, **이번 달 모델별 사용 내역**(몇 번 호출했고 몇 크레딧 썼는지).
- 크기가 큰 모델이나 화면 첨부는 크레딧을 더 써요. **간단한 질문은 작은 모델**(예: Flash, Haiku, mini 계열)을 쓰면 아낄 수 있어요.
- 남은 크레딧이 **10% 이하**가 되면 한 번 알려 줘요.
- 크레딧을 다 쓰면 **이 앱(API)으로는 새 질문을 할 수 없어요.** 문서상 무료 모델(GPT-5 nano 등)은 API로 호출할 수 없고, 웹(aichat.kku.ac.kr)에서만 쓸 수 있어요. 그때는 "이번 달 크레딧을 모두 썼어요. 11월 1일에 초기화돼요"라고 안내해요.

### 화면 보고 질문하기

비서처럼 "이 오류 무슨 뜻이야?", "여기 표 요약해 줘"처럼 **지금 화면을 보면서** 물어볼 수 있어요.

- **기본은 꺼짐**이에요. 말풍선의 **📷 화면 첨부** 버튼을 켜면, 질문을 보낼 때마다 그 순간의 **화면 전체를 캡처해서 함께 전송**해요. (펫과 말풍선은 캡처에서 제외돼요.) 처음 켤 때 한 번 안내 창이 나와요. 설정은 저장돼요.
- **✂ 영역 선택**: 누르면 화면이 어두워지면서 드래그로 영역을 고를 수 있어요. 고른 영역이 **다음 질문 한 번에** 첨부되고(작은 미리보기가 보여요), 그 질문은 화면 전체 대신 이 영역만 보내요. 미리보기의 ✕로 취소할 수 있고, `Esc`나 마우스 오른쪽 버튼으로 선택을 취소해요.
- 보낸 메시지에는 `📷 화면 첨부` / `✂ 선택 영역 첨부` 표시가 붙어요.
- 글씨가 작아서 안 읽히면 **영역 선택**으로 그 부분만 크게 보내 보세요.
- 이미지를 보내는 데 문제가 생기면(서버가 거부하는 등) 말풍선에 안내가 나와요. 그때는 📷를 꺼서 글만 보내 보세요.
- 화면을 계속 지켜보지는 않아요. 📷를 켠 상태에서 **질문을 보내는 순간에만** 한 번 캡처해요. (✂ 영역 선택은 📷가 꺼져 있어도 그 질문에만 적용돼요.)

> ⚠️ **화면에 보이는 모든 것이 서버로 전송돼요.** 메신저, 비밀번호, 개인 문서가 열려 있을 땐 📷를 끄거나 ✂로 필요한 부분만 고르세요.

## 5. 캐릭터 바꾸기

### 햄스터 4종 (색 테마 포함)

기본으로 **도토리 · 치즈 · 먹구름 · 알밤** 햄스터가 들어 있어요. 처음에는 도토리예요.

- **설정 → 햄스터**에서 고르거나, 캐릭터 **우클릭 → 햄스터 색상**에서 바로 바꿀 수 있어요.
- 햄스터를 바꾸면 **말풍선과 설정 창의 색도 그 햄스터 색으로** 같이 바뀌어요. (설정 창에서는 고르는 즉시 미리 볼 수 있어요.)

## 6. 설정 항목

트레이 아이콘 → **설정**, 또는 캐릭터 우클릭 → **설정**.

| 항목 | 설명 |
|---|---|
| 햄스터 | 도토리 · 치즈 · 먹구름 · 알밤. 고르면 말풍선·설정 창 색도 함께 바뀌어요 |
| 이름 | 말풍선 위에 표시되고, 캐릭터가 자기 이름으로 인식해요 |
| 이번 달 크레딧 | 남은 양, 초기화 날짜, 모델별 사용 내역 (키를 저장하면 보여요) |
| 글자 크기 | 작게 · 보통 · 크게 · 아주 크게 (말풍선과 큰 대화창) |
| API 키 | 건국대 AI 게이트웨이에서 발급한 키. 저장된 키는 설정 창에서 삭제할 수 있어요 |
| AI 모델 | AI 종류(Claude/GPT/Gemini/Grok/Perplexity) 탭에서 모델을 선택. 목록에 없으면 모델 ID를 직접 입력할 수도 있어요. 말풍선 위쪽에 지금 답하는 모델 이름이 표시돼요 |

말투는 항상 존댓말이고, 답변은 말풍선에서 읽기 쉽게 핵심부터 짧은 문단과 목록으로 나와요.

## 7. 개인정보 · 보안

- **API 키**는 Windows 계정에 묶인 방식으로 **암호화**되어 내 컴퓨터에만 저장돼요. 화면(렌더러)은 키 값을 볼 수 없고, 키는 건국대 게이트웨이 주소로만 전송돼요.
- **대화 내용**은 답변을 만들기 위해 게이트웨이 서버로 전송돼요. 민감한 개인정보는 입력하지 마세요.
- **화면 캡처**는 📷가 ON일 때 질문을 보낼 때마다 함께 전송돼요(기본값은 **꺼짐**, 켤 때 안내가 나와요). 캡처 이미지는 내 컴퓨터에 **저장하지 않고**, 대화 기록에는 "화면 첨부" 표시만 남아요. 민감한 화면이 열려 있을 땐 📷를 끄세요.
- 대화 기록은 내 컴퓨터의 `%APPDATA%\cutie-pet\history.enc`에 **암호화**되어 저장돼요. (API 키와 같은 방식이라 같은 Windows 계정에서만 읽을 수 있어요. 이전 버전의 `history.json`은 처음 실행할 때 자동으로 암호화돼요.) 공용 PC에서 썼다면 **대화 초기화**를 하거나 앱 삭제 후 이 폴더도 지우세요.
- 앱을 삭제해도 `%APPDATA%\cutie-pet\`(설정·대화 기록)는 남아요. 완전히 지우려면 이 폴더를 직접 삭제하세요.

## 8. 문제 해결

| 증상 | 해결 |
|---|---|
| 설치할 때 "PC 보호" 경고 | `추가 정보` → `실행` |
| "API 키가 없어 / 올바르지 않아" | 설정에서 키를 다시 입력하세요. 건국대 AI 게이트웨이에서 발급한 키인지, 복사할 때 앞뒤 공백이 없는지 확인하세요 |
| "인터넷에 연결이 안 되나 봐" | 네트워크를 확인하세요. 학교/회사 망에서 막혀 있을 수도 있어요 |
| "모델을 찾을 수 없대" | 설정 → AI 모델 → **목록 새로고침**으로 실제 있는 모델을 고르세요 |
