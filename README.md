# 햄스티 (Hamstie) 🐹

바탕화면 위에 사는 귀여운 펫 캐릭터와 **Claude**로 대화하는 데스크톱 앱이에요.
건국대학교 AI 게이트웨이의 API 키로 동작하고, 캐릭터(햄스터 4색)와 이름을 바꾸고, 쓸 AI 모델도 골라서 쓸 수 있어요. 말투는 항상 공손한 존댓말이에요.

[**⬇️ 최신 버전 다운로드**](https://github.com/scarypants/hamstie-releases/releases/latest)

> **건국대 학생이라면**: 아래 [1. 설치](#1-설치) → [2. API 키 발급](#2-api-키-발급) → [3. 처음 실행](#3-처음-실행하기) 순서로 따라 하면 5분이면 끝나요.

> ⚠️ **이용 전에 반드시 읽어 주시기 바랍니다.**
> - 이 앱은 **학생 개인이 만든 비공식 서비스**입니다. 건국대학교가 검증하거나 운영하는 서비스가 아니며, 학교는 이 앱의 보안성, 안정성, 데이터 보호 정책을 보증하지 않습니다.
> - 질문과 첨부한 화면은 학교 AI 게이트웨이 서버로 전송되며, 입력한 내용이 외부 서버에 수집되거나 노출될 가능성을 완전히 배제할 수 없습니다.
> - 서비스 이용 중 발생하는 **API 과금, 데이터 유출, 개인정보 노출 등 모든 보안 사고와 금전적 손실의 책임은 개발자 및 사용자 본인**에게 있으며, 학교는 어떠한 책임도 지지 않습니다.
> - 중요한 연구 데이터나 개인정보는 이 앱에 입력하지 않아야 하며, 학교가 공식 지원하는 보안 환경(FactChat 등)을 이용하시기 바랍니다.
> - 사용자 책임 사항의 전문은 [**이용 안내(TERMS)**](TERMS.md)에 있으며, 앱을 처음 실행할 때 동의를 받습니다.

## 1. 설치

1. [**Releases 페이지**](https://github.com/scarypants/hamstie-releases/releases/latest)에서 가장 최신 버전의 `Hamstie-Setup-x.x.x.exe`를 내려받으세요.
2. 파일을 실행하면 자동으로 설치되고 바로 앱이 켜져요. (관리자 권한, Node.js 설치 모두 필요 없어요.)
3. **"Windows의 PC 보호" 화면이 뜨면** 앱이 정식 서명 인증서 없이 배포돼서 나오는 경고예요.
   `추가 정보` → `실행`을 누르면 돼요. 공식 릴리스에서 받은 파일인지는 릴리스 노트에 적힌 **SHA-256 체크섬**과 비교해 확인할 수 있어요.
   ```
   certutil -hashfile "Hamstie-Setup-x.x.x.exe" SHA256
   ```

- 지원: Windows 10 / 11 (64비트)
- 설치 위치: `%LOCALAPPDATA%\Programs\Hamstie`
- 삭제: Windows 설정 → 앱 → 설치된 앱 → **Hamstie** 삭제

## 2. API 키 발급

이 앱은 **건국대 AI 게이트웨이에서 발급한 API 키로만** 동작해요. (다른 서비스의 키는 사용할 수 없어요.)

1. <https://aichat.kku.ac.kr/dashboard/developers?tab=key> 에 접속해서 학교 계정으로 로그인하세요.
2. 개발자(Developers) 페이지에서 **API 키를 발급**하고 복사해 두세요.
   (화면 구성은 학교 서비스 사정에 따라 달라질 수 있어요.)

> ⚠️ **API 키는 비밀번호와 같아요.**
> 카톡·깃허브·스크린샷 등 다른 사람이 볼 수 있는 곳에 절대 올리지 마세요.
> 실수로 노출했다면 발급 페이지에서 키를 폐기하고 새로 발급하세요.

## 3. 처음 실행하기

앱을 처음 켜면 먼저 **이용 안내 창**이 떠요. 요약을 읽고(**전체 내용 보기**로 전문도 볼 수 있어요) 동의해야 시작돼요. 동의하지 않으면 앱이 종료돼요. 이때 **내 개인 PC인지, 공용 PC인지**도 골라요. (공용 PC라면 아래 [공용 PC에서 쓸 때](#공용-pc에서-쓸-때)를 먼저 읽어 보세요.)

이어서 **설정 창**이 자동으로 열려요.

1. **API 키** 칸에 발급받은 키를 붙여 넣어요.
2. (선택) **햄스터**와 **이름**을 골라요.
3. (선택) **AI 모델**에서 쓸 AI를 골라요. **Claude · GPT · Gemini · Grok · Perplexity** 탭에서 모델을 고르면 돼요. 키를 입력하면 쓸 수 있는 모델 목록이 자동으로 나오고, 고르지 않으면 기본 모델(`claude-sonnet-5-5`)을 써요.
4. **저장**을 누르면 끝! 오른쪽 아래에 캐릭터가 나타나요.

## 4. 사용법

| 동작 | 결과 |
|---|---|
| 캐릭터 **클릭** | 말풍선 입력창 열기 / 다시 클릭하면 닫기 |
| **Enter** | 메시지 보내기 (**Shift+Enter**는 줄바꿈) |
| **Esc** | 답변 중지 (답변이 없을 땐 말풍선 닫기) |
| **Ctrl + Alt + H** | 어디서든 펫을 불러서 바로 입력 (창이 숨겨져 있어도 나타나요) |
| 보내기 버튼이 **■**일 때 | 누르면 답변을 중지해요 |
| 캐릭터 **드래그** | 화면 어디로든 옮기기 (위치는 저장돼요) |
| **📷 화면 첨부** 버튼 | 켜면 질문마다 화면도 함께 보내요 (기본은 **꺼짐**, 아래 [화면 보고 질문하기](#화면-보고-질문하기) 참고) |
| **✂ 영역 선택** 버튼 | 화면에서 드래그로 영역을 골라 그 부분만 첨부 |
| 말풍선 위쪽의 **⤢** 버튼 | 큰 대화창 열기 |
| 캐릭터 **우클릭** | 메뉴 열기 (아래 참고) |
| **트레이 아이콘** (작업표시줄 오른쪽) | 펫 보이기/숨기기, 설정, 공용 PC 모드로 다시 시작, 종료 |

**우클릭 메뉴**

- **햄스터 색상**: 도토리 · 치즈 · 알밤 · 검정깨
- **크기 조절**: 작게 · 보통 · 크게
- **가끔 산책하기**: 켜 두면 가만히 있을 때 가끔 좌우로 걸어 다녀요
- **대화 초기화**: 이전 대화를 모두 지워요
- **설정** / **종료**

**알아두면 좋은 점**

- 대화는 최근 20턴까지 기억해서 맥락이 이어져요.
- 말풍선에는 내가 보낸 말과 답변이 함께 보여요. 30초 뒤에 자동으로 닫히지만(**마우스를 올려 두거나 스크롤하는 동안, 글을 쓰는 중이거나 답을 받는 중에는 닫히지 않아요**) 대화 내용은 남아 있어요.
- 답변을 기다리는 동안(생각 중)은 **작은 햄스터 3마리가 하나씩 나타났다 사라지는** 애니메이션이 나와요. (선택한 햄스터 모습 그대로예요.)
- 답변이 오기 시작하면 **글자가 하나씩 나타나요.** 깜빡이는 커서가 보이는 동안은 보내기 버튼이 **■ 중지**로 바뀌어요. 중지하면 지금까지 쓴 부분은 남아요.
- 마지막 답변 아래의 **↻ 다시 생성**을 누르면 같은 질문에 새 답변을 받아요. (화면을 함께 보냈다면 같은 화면으로 다시 물어봐요.)
- 말풍선 위쪽 모델 이름 옆의 **`2,986 / 3,000 크레딧`**은 **이번 달 남은 크레딧 / 한도**예요. 20% 이하면 주황색, 5% 이하면 빨간색으로 바뀌고, 마우스를 올리면 `남은 양 / 한도 · 초기화 날짜`가 나와요.
- 답변 아래의 **`약 4.2 크레딧 사용`**은 **그 답변에 쓴 크레딧**이에요. (질문 전후 잔액의 차이라서, 같은 시간에 웹에서 쓴 양이 섞이면 조금 다를 수 있어요.) 질문마다 얼마나 드는지 확인하면서 모델을 고르세요.
- 설정의 **글자 크기**(작게 · 보통 · 크게 · 아주 크게)로 말풍선과 큰 대화창의 글자 크기를 바꿀 수 있어요.
- 답변의 **마크다운 서식**(굵게, 기울임, 목록, `코드`, 코드 블록, 제목, 인용, 링크)이 보기 좋게 표시돼요. 링크를 누르면 기본 브라우저로 열려요. (표는 지원하지 않아요.)
- 말풍선은 대화가 길어져도 창 위쪽이 잘리지 않고, 넘치면 안에서 스크롤돼요.
- 새 답변이 오면 **답변의 맨 처음부터** 보여요. 답변이 말풍선보다 길어도 아래부터 보이지 않고, 처음부터 읽으면서 스크롤하면 돼요.
- 말풍선 위쪽의 **⤢** 버튼(또는 말풍선보다 긴 답변 아래에 나타나는 **큰 창에서 보기**)으로 **큰 대화창**을 열 수 있어요. 크기를 마음대로 조절할 수 있고, 지금까지의 대화를 한눈에 읽고 답변을 **복사**할 수 있어요. 대화는 말풍선에서 계속 이어가면 큰 창에도 바로 반영돼요.
- 말풍선의 **위·왼쪽·오른쪽 가장자리**나 **왼쪽 위 모서리**를 끌어서 말풍선 크기를 직접 조절할 수 있어요. 위로 끌면 더 위쪽까지 늘어나요. 크기는 저장되고, 가장자리를 **더블클릭**하면 원래 크기로 돌아와요.
- 말풍선 위쪽의 **⚙** 버튼으로 바로 설정을 열 수 있어요. (우클릭 메뉴와 트레이에서도 열 수 있어요.)
- 말풍선은 화면 가장자리에서도 잘리지 않게 안쪽으로 밀려요.

### 크레딧 (월 3,000)

건국대 KU LLM은 **매달 1인당 3,000 크레딧**이 지급되고 **매월 1일에 초기화**돼요(남은 크레딧은 이월되지 않아요). 이 앱은 게이트웨이의 잔액·사용량 조회 기능을 써서 보여 줘요.

- **설정 → 이번 달 크레딧**: 남은 크레딧 막대, 다음 초기화 날짜, **이번 달 모델별 사용 내역**(몇 번 호출했고 몇 크레딧 썼는지).
- 크기가 큰 모델이나 화면 첨부는 크레딧을 더 써요. **간단한 질문은 작은 모델**(예: Flash, Haiku, mini 계열)을 쓰면 아낄 수 있어요.
- 남은 크레딧이 **10% 이하**가 되면 한 번 알려 줘요.
- 크레딧을 다 쓰면 **이 앱(API)으로는 새 질문을 할 수 없어요.** 문서상 무료 모델(GPT-5 nano 등)은 API로 호출할 수 없고, 웹(aichat.kku.ac.kr)에서만 쓸 수 있어요. 그때는 "이번 달 크레딧을 모두 썼어요. 11월 1일에 초기화돼요"라고 안내해요.

### 화면 보고 질문하기

비서처럼 "이 오류 무슨 뜻이야?", "여기 표 요약해 줘"처럼 **지금 화면을 보면서** 물어볼 수 있어요.

- **기본은 꺼짐**이에요. 말풍선의 **📷 화면 첨부** 버튼을 켜면, 질문을 보낼 때마다 그 순간의 **화면 전체를 캡처해서 함께 전송**해요. (펫과 말풍선은 캡처에서 제외돼요.) 처음 켤 때 한 번 안내 창이 나와요. 설정은 저장돼요.
- **✂ 영역 선택**: 누르면 화면이 어두워지면서 드래그로 영역을 고를 수 있어요. 고른 영역이 **다음 질문 한 번에** 첨부되고(작은 미리보기가 보여요), 그 질문은 화면 전체 대신 이 영역만 보내요. 미리보기의 ✕로 취소할 수 있고, `Esc`나 마우스 오른쪽 버튼으로 선택을 취소해요.
- **보내기 전에 한 번 더 확인해요.** 화면이 서버로 나가기 직전에 **미리보기 창**이 열려요. 보이면 안 되는 곳(이름, 메시지, 비밀번호 등)을 **네모나 붓으로 드래그해 가리고**(Ctrl+Z로 되돌리기), `보내기`를 누르면 돼요. `보내지 않음`(Esc)을 누르면 아무것도 전송되지 않고 질문은 입력창에 돌아와요.
  - 가린 부분은 검은색으로 **이미지에 구워져서** 전송돼요. 가리기 전의 원본은 보내는 즉시 앱에서 버려요.
  - 이 확인 창은 설정의 **화면 첨부 → 화면을 보내기 전에 확인하고 가리기**에서 끌 수 있어요. 끄면 화면이 확인 없이 그대로 전송돼요.
- 보낸 메시지에는 `📷 화면 첨부` / `✂ 선택 영역 첨부` 표시가 붙어요.
- 글씨가 작아서 안 읽히면 **영역 선택**으로 그 부분만 크게 보내 보세요.
- 이미지를 보내는 데 문제가 생기면(서버가 거부하는 등) 말풍선에 안내가 나와요. 그때는 📷를 꺼서 글만 보내 보세요.
- 화면을 계속 지켜보지는 않아요. 📷를 켠 상태에서 **질문을 보내는 순간에만** 한 번 캡처해요. (✂ 영역 선택은 📷가 꺼져 있어도 그 질문에만 적용돼요.)

> ⚠️ **화면에 보이는 모든 것이 서버로 전송돼요.** 메신저, 비밀번호, 개인 문서가 열려 있을 땐 📷를 끄거나 ✂로 필요한 부분만 고르고, 미리보기 창에서 가려 주세요.

### 공용 PC에서 쓸 때

도서관, 실습실 같은 **공용 PC에서는 반드시 공용 PC 모드**로 쓰세요. (신뢰할 수 없는 PC에는 API 키를 입력하지 않는 것이 원칙이에요.)

- **켜는 방법**: 처음 실행할 때 "공용 PC"를 고르거나, 설정 → **저장과 보관** 또는 트레이 메뉴의 **공용 PC 모드로 다시 시작…**을 눌러요. 실행 옵션으로는 `Hamstie.exe --public`이에요.
- **이 모드에서는**: 키, 대화, 설정을 **디스크에 저장하지 않아요.** (저장 위치도 임시 폴더로 바뀌고, 앱을 끄면 지워요.) 앱을 켤 때마다 키를 입력하고 이용 안내에 동의해요. **화면 첨부는 쓸 수 없어요.**
- **공용 PC 전용 키를 따로 발급**해서 쓰고, 다 쓰면 **폐기**하세요. 앱은 게이트웨이의 키를 폐기할 수 없어서, 종료할 때 뜨는 안내의 **키 폐기 페이지 열고 종료**를 누르면 발급 페이지가 열려요. 거기서 직접 폐기해야 해요.
- 한계: 공용 PC에 키 입력 기록 프로그램, 화면 녹화 프로그램, 원격 제어 도구가 있으면 앱이 막을 수 없어요.

## 5. 캐릭터 바꾸기

### 햄스터 4색 (색 테마 포함)

기본으로 **도토리 · 치즈 · 알밤 · 검정깨** 햄스터가 들어 있어요. 처음에는 도토리예요.

- **설정 → 햄스터**에서 고르거나, 캐릭터 **우클릭 → 햄스터 색상**에서 바로 바꿀 수 있어요.
- 햄스터는 평소에 **가만히 서 있다가**, 한동안 쓰지 않으면 **통통 뛰며 가끔 눈을 깜박**여요. 아주 가끔 **조금 걸어갔다 돌아오고**, 말풍선을 열면 다시 **가만히 서 있어요**.
- 햄스터를 바꾸면 **말풍선과 설정 창의 색도 그 햄스터 색으로** 같이 바뀌어요. (설정 창에서는 고르는 즉시 미리 볼 수 있어요.)

## 7. 개인정보 · 보안

이 장은 앱이 데이터를 어떻게 다루는지를 설명합니다. 사용자 책임 사항의 전문은 [이용 안내(TERMS)](TERMS.md)를 참고하시기 바랍니다.

- **서버**: 개발자가 운영하는 서버는 없습니다. 개발자는 키와 대화 내용을 수집하지 않으며, 앱은 사용자 PC에서 학교 게이트웨이 주소로만 요청을 보냅니다. (그 외 주소로는 요청을 보내지 않고, 주소가 바뀌어 다른 서버로 안내(리다이렉트)되는 응답도 따라가지 않습니다.) 게이트웨이 서버에서의 보관, 기록, 노출 여부는 개발자가 알 수 없고 보증할 수 없습니다.
- **API 키**: Windows 계정에 묶인 방식으로 **암호화**되어 사용자 PC에만 저장됩니다. 화면(렌더러)은 키 값을 볼 수 없습니다. 설치본은 환경변수나 `.env`의 키를 읽지 않습니다.
- **대화 내용**: 답변을 만들기 위해 게이트웨이 서버로 전송됩니다. 민감한 개인정보는 입력하지 않아야 합니다.
- **화면 캡처**: 📷가 켜져 있을 때 질문을 보낼 때마다 함께 전송됩니다(기본값은 **꺼짐**, 켤 때 안내가 나옵니다). 전송 직전에 미리보기 창에서 가릴 수 있고(설정에서 끌 수 있음), 가린 결과만 전송됩니다. 캡처 이미지는 사용자 PC에 **저장하지 않고**, 대화 기록에는 "화면 첨부" 표시만 남습니다.
- **대화 기록 보관**: `%APPDATA%\hamstie\history.enc`에 **암호화**되어 저장되며(같은 Windows 계정에서만 읽을 수 있음), **보낸 지 7일이 지나면 자동으로 삭제**됩니다. 이 기간은 사용자 PC에 저장된 기록에만 적용되고, 게이트웨이 서버의 보관에는 적용되지 않습니다. 이전 버전의 평문 `history.json`은 처음 실행할 때 암호화본으로 옮기고 지웁니다.
- **오류 기록**: 문제 원인을 찾을 수 있도록 `%APPDATA%\hamstie\error.log`에 시각, 위치, 오류의 종류만 남깁니다(최대 64KB). 질문, 답변, 키, 화면 내용, 오류 메시지 본문은 기록하지 않으며 공용 PC 모드에서는 기록하지 않습니다.
- **링크**: 답변 속 링크는 https 주소만, 사이트 이름을 보여 주고 확인을 받은 뒤 브라우저로 엽니다. 새 버전은 앱이 몰래 확인하지 않고, 트레이 메뉴의 **새 버전 확인**을 눌렀을 때만 릴리스 페이지를 엽니다.
- **암호화를 쓸 수 없는 PC**: 키와 대화를 저장하지 않고 앱이 켜져 있는 동안에만 보관합니다. 앱을 켤 때마다 키를 입력해야 합니다.
- **삭제**: 설치 프로그램으로 앱을 삭제할 때 `%APPDATA%\hamstie\`(설정, 대화 기록)도 함께 삭제되도록 구성되어 있으나, 폴더가 남아 있으면 직접 삭제하시기 바랍니다. 대화만 지우려면 **대화 초기화**를 사용하시기 바랍니다.
- **키 폐기**: 앱의 "키 삭제"는 이 PC에 저장된 키만 지웁니다. 게이트웨이는 키 발급·폐기 기능을 API로 제공하지 않으므로, 키 자체의 폐기는 [키 관리 페이지](https://aichat.kku.ac.kr/dashboard/developers?tab=key)에서 직접 해야 하며, 설정의 **키 폐기하러 가기**가 그 페이지를 엽니다. (발급은 **키 발급하러 가기**)
- **공용 PC**: [공용 PC에서 쓸 때](#공용-pc에서-쓸-때)의 공용 PC 모드를 사용하시기 바랍니다.

## 8. 문제 해결

| 증상 | 해결 |
|---|---|
| 설치할 때 "PC 보호" 경고 | `추가 정보` → `실행` |
| "API 키가 없어 / 올바르지 않아" | 설정에서 키를 다시 입력하세요. 건국대 AI 게이트웨이에서 발급한 키인지, 복사할 때 앞뒤 공백이 없는지 확인하세요 |
| "인터넷에 연결이 안 되나 봐" | 네트워크를 확인하세요. 학교/회사 망에서 막혀 있을 수도 있어요 |
| "모델을 찾을 수 없대" | 설정 → AI 모델 → **목록 새로고침**으로 실제 있는 모델을 고르세요 |
| "요청이 너무 많아요" | 한 사람당 1분에 120번까지예요. 안내된 초만큼 기다렸다가 다시 말을 걸어 보세요. (짧은 대기는 앱이 알아서 기다렸다가 다시 보내요) |
| "이번 달 크레딧을 모두 썼어요" | 다음 초기화(매월 1일)까지 API로는 못 써요. 무료 모델은 웹 aichat.kku.ac.kr 에서 쓰세요 |
| "API로는 쓸 수 없는 모델이에요" | 무료 모델 등은 API에서 막혀 있어요. 설정에서 다른 모델을 고르세요 |
| "이 API 키는 폐기됐어요 / 꺼져 있어요" | 발급 페이지에서 새 키를 만들거나 키를 다시 켜세요 |
| "서비스가 점검 중이에요" | 점검이 끝난 뒤에 다시 해 보세요 |
| 답변이 비어 있어요 | 추론형 모델(GPT-5 계열 등)에서 가끔 있어요. 다시 시도하거나 다른 모델을 고르세요 |
| "화면 이미지를 보내는 데 문제가 있었어" | 📷를 꺼서 글만 보내거나, ✂ 영역 선택으로 작은 영역만 보내 보세요 |
| 화면 캡처에 펫이 같이 찍혀요 | Windows 10 (2004 이상) / 11에서는 펫이 캡처에서 제외돼요. 구버전 Windows에서는 펫이 까맣게 보일 수 있어요 |
| 공용 PC에서 쓰고 싶어요 | 트레이 아이콘 → **공용 PC 모드로 다시 시작…** (또는 `Hamstie.exe --public`) |
| 암호화 저장을 쓸 수 없다는 안내가 나와요 | 이 PC에서는 키와 대화를 저장하지 않아요. 앱을 켤 때마다 키를 입력하세요 |
| 화면을 보내려는데 미리보기 창이 떠요 | 정상이에요. 가릴 곳을 가리고 `보내기`를 누르세요. 끄려면 설정 → 화면 첨부 |
| 캐릭터가 안 보여요 | 트레이 아이콘 → **펫 보이기** |
| 설정 창이 안 열려요 | 트레이 아이콘 → **설정** |

그래도 안 되면 [Issues](https://github.com/scarypants/hamstie-releases/issues)에 증상을 남겨 주세요. **API 키나 대화 내용은 절대 적지 마세요.**
